## 【ゲーム紹介】
本作は、自身の「分身」を召喚し、協力しながら戦う3Dアクションゲームです。
しかし、召喚された分身は時間経過とともに制御不能となり、**最終的にはプレイヤーに襲いかかる「敵」へと変貌を遂げます。**
分身の強力な手数を活かして一気に攻め立てるか、あるいはリスクを考慮して制御を保つか――。分身をいかにマネジメントするかが勝敗を分ける、戦術的かつ爽快なバトルが特徴です。

## 【技術的なこだわり】（手触りと堅牢性の両立）

プレイヤーキャラクターの担当として、デビルメイクライやFF16のような「動かしていて気持ち良い」と感じる**手触り（ゲームフィール）の言語化と数値制御**、およびチーム開発に耐えうる**疎結合なシステム設計**を徹底しました。

### 1. 先行入力（インプットバッファ）とコンボシステム
ただアニメーションを再生するだけでなく、攻撃モーション中に次の入力を受け付ける「コンボウィンドウ（`bComboWindowOpen`）」を管理。窓口が開く前の早い入力に対しても、フラグ（`bComboInputBuffered`）を用いて「先行入力」としてスタックします。連打や目押しなど、プレイヤーの操作癖に左右されず、意図したタイミングで次段へスムーズに派生するノンストレスなコンボフィールを実現しています。

### 2. 数式（イージング関数）を用いた微細なゲームフィールの調整
「気持ちよさ」を感覚で終わらせず、数学的なアプローチで制御しています。
* **着地硬直からの復帰:** 単なる線形補間（`Lerp`）ではなく、イージング関数（`FMath::InterpEaseIn`）を採用。「着地直後は重く、後半にかけて急速に元の速度へ戻る」という動的な緩急（カーブ）をつけることで、着地の重量感とアクションのキレを両立させました。
* **オートダッシュ:** 一定時間走り続けるとシームレスにダッシュ状態へ移行する機能を実装し、広大な3D空間での移動ストレスを排除しています。

### 3. 物理法則をハックする「キレのある回避挙動」
 CharacterMovementComponentの物理仕様をそのまま使うと、移動の慣性が残ってしまいスタイリッシュなキレが出ません。そこで回避（`Dodge`）アクションの瞬間のみ、キャラクターの重力と地面摩擦（`GravityScale`, `GroundFriction`）を一時的に完全にゼロ（`0.f`）化。そのクリーンな状態で `LaunchCharacter` を用いて鋭い推進力を与えています。タイマー処理による回避終了と同時に物理パラメータを安全に復元する状態管理を行っています。

### 4. ベクトル数学（内積）を応用した直感的なロックオン切り替え
ロックオン中に右スティックを入力した際、カメラの「右ベクトル」と「現在のターゲットから他の敵候補への方向ベクトル」の**内積（Dot Product）**を計算。画面上の右側・左側にいる最適な敵を数学的に判定し、直感的なターゲット切り替えロジックをスクラッチで実装しました。
また、激しい操作による暴発（チャタリング）を防ぐため、「入力クールダウン（`SwitchCooldown`）」や「スティックの中央戻り判定の閾値（`SwitchThreshold`）」を設け、格闘ゲーム並みの堅牢性を担保しています。

### 5. 堅牢なイベント駆動（デリゲート）とポインタの安全管理
Unreal EngineのC++開発において最も警戒すべき「ヌルポインタによるクラッシュ」を防ぐ設計を徹底しています。
* **自動解除機能:** 敵の死亡イベント（`OnEnemyEliminated`）を動的デリゲートで購読。ロックオン対象が倒された瞬間に安全かつ即座にロックオンを解除し、ライフサイクル管理を徹底。
* **疎結合なコンポーネント連携:** 攻撃ヒット時にマルチキャストデリゲートを通じてコアクラスへエネルギー（`CurrentEnergy`）を還元し、一定量に達すると「残像（分身）システム」へ通知して召喚（`SummonGhost`）を可能にするなど、各コンポーネントが直接依存し合わない綺麗なアーキテクチャを構築しています。

### 6. 3D空間とUIを同期させるHUDの動的スケーリング
ロックオンマーカーの描画において、敵の3D座標を2Dスクリーン座標に投影（`ProjectWorldLocationToScreen`）するだけでなく、プレイヤーと敵との距離（`Distance`）を動的に計算。距離に反比例してマーカーのサイズを `Clamp` 付きで伸縮させるスケーリングロジックを実装し、敵との距離感を視覚的にも掴みやすくする工夫を施しています。

## 【操作方法】

### キーボード & マウス
| 入力キー | アクション |
| :--- | :--- |
| `W` `A` `S` `D` | 前後左右移動 |
| `W` `A` `S` `D`（長押し） | ダッシュ移動 |
| `矢印キー` | カメラ操作 |
| `Space` | ジャンプ（2段ジャンプ対応） |
| `Enter` | 攻撃（最大4段コンボ） |
| `E` | 分身召喚 |
| `R` | ロックオン / ロックオン解除 |

### ゲームパッド
| 入力ボタン | アクション |
| :--- | :--- |
| `左スティック` | 前後左右移動 |
| `左スティック`（深く長押し） | ダッシュ移動 |
| `右スティック` | カメラ操作 / （ロックオン中）ターゲット切り替え |
| `Aボタン` | ジャンプ（2段ジャンプ対応） |
| `Yボタン` | 攻撃（最大4段コンボ） |
| `Bボタン` | 分身召喚 |
| `左スティック押し込み` | ロックオン / ロックオン解除 |
